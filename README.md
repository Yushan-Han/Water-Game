# Water Game
最新版导出：v27，包含手机布局、音量控制及后台暂停处理。

## 上传到 GitHub
1. 先解压本压缩包，不要直接把 ZIP 上传到仓库。
2. 打开 https://github.com/Yushan-Han/Water-Game
3. 点击 Add file → Upload files；空仓库点击 uploading an existing file。
4. 把解压后里面的全部文件和 assets 文件夹一起拖进去。
   index.html 必须直接位于仓库根目录，不能额外套一层文件夹。
5. 点击 Commit changes。
6. Settings → Pages → Deploy from a branch → main → /(root) → Save。
7. 等待发布完成，点击 Pages 页面里的 Visit site。

本项目无需安装依赖或构建。
.nojekyll 是空文件，用来跳过 Jekyll。若系统隐藏它，可在 GitHub 仓库根目录
用 Add file → Create new file 新建 .nojekyll（内容留空或一行空白）。
大陆访问效果仍需使用当地网络实际测试。
